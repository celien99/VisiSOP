# INTERACTION RULES — v1.0 / 检测系统控制台

**状态**：v1.0，随 `DESIGN_BRIEF.md` v1.0 与 `DESIGN_SYSTEM.md` v1.0 定稿。取代 v0.1「运行账本」的交互规则。
**优先级**：系统行为以 `docs/AI_SOP_Platform_Architecture_v2.0.md` 与 `docs/AI_SOP_Architecture_Design_v1.1.md` 为准；本文只规定前端如何呈现与响应，不新增领域语义。冲突时停止实现，先补 ADR。

用 **MUST / MUST NOT** 写可测试的规则。每条都应在 Playwright 或人工验收中有对应检查（见 §10）。

## 1. 数据权威与新鲜度

### 1.1 权威来源

- **MUST** 以 REST 快照为权威。首次加载、重连、窗口重新获得焦点、手动刷新，都从 REST 取快照。
- **MUST** 把 WS 消息当作"该刷新了"的信号：收到后按查询键 invalidate/refetch，不把消息内容当最终状态写进缓存。
- **MUST** 用 `message_id` 去重；重复或回退的消息忽略。
- **MUST NOT** 在前端根据视觉事件、置信度、步骤顺序推导 SOP 结论。前端只显示后端给出的步骤状态、`reason_code`、告警与允许动作。
- **MUST NOT** 由前端计算看板上的聚合指标并当作事实展示；计数、均值、可用率都来自后端。前端只做格式化。

### 1.2 断线与重连

- WS 断开时，顶栏连接状态变为"连接中断"，并显示最近一次成功快照的时间与年龄。
- **MUST NOT** 在断线期间继续显示"实时"或"已连接"。
- 重连退避：1s → 2s → 4s → 8s → 16s → 30s，带抖动；成功后重置。
- 重连成功后，**MUST** 先重新拉取当前页面所有可见查询，再显示"已连接"。
- 断线期间允许每 15s 做一次 REST 兜底刷新（阶段 1 默认）；重连后停止兜底轮询。
- 页面隐藏时暂停重连与轮询；重新可见时立即刷新一次。

### 1.3 过期与局部失败

- 监控墙的快照超过 10s 未更新，状态栏显示 `快照已过期 Ns`；看板阈值 60s（聚合本来就有延迟）；历史/详情页 30s。阈值是 UI 策略，后端若有新鲜度字段则以其为准。
- 过期数据可以继续显示，但 **MUST** 带过期标记；不得把旧数据当新数据。
- 过期时**不得**继续写"实时"。画面卡的画面性质降级为 `最后一帧`，并显示该帧时间。
- 一个面板/一格请求失败，**MUST** 只在该范围显示错误与重试；其他格子与面板继续可用。
- 监控墙的核心（导航、筛选、班次条、状态栏）在任何局部失败下都不得消失。

## 2. 监控墙

### 2.1 筛选与 URL

- 区域筛选、"只看需要处理"、机位排序 **MUST** 写入 URL search params；刷新/分享/后退可恢复。
- 建议参数：`zone`、`attention=1`、`sort`、`focus`。
- 筛选变化时**不得**整页闪骨架；保留现有格子，只更新受影响的格子。
- 空结果必须说明"当前筛选没有需要处理的机位"，并给出清除筛选；**MUST NOT** 写"一切正常"如果快照已过期。

### 2.2 格子的状态与动作

- 每格是**一个**可点击目标，进入工位详情。格内不得放多个竞争性按钮。
- 处置条（待确认/异常）是格子的主操作提示；点击处置条与点击格子结果相同，不进入两条不同的流程。
- **MUST NOT** 在格子上直接提供"通过/驳回"验证性按钮——复核是带依据的决定，必须进入详情。
- 状态章、进度轨、当前步骤、画面性质都来自后端字段；前端只做映射（`DESIGN_SYSTEM.md` §3.3）。
- 排序默认：待确认（最久优先）→ 异常（最新优先）→ 离线 → 正常。**MUST NOT** 改变格子相对位置而不给理由；自动重排时保留 120ms 过渡并在状态栏提示"顺序已按最新状态更新"。

### 2.3 画面

- 画面性质必须显式：`实时预览` / `最后一帧 HH:MM:SS` / `无信号`。三者视觉不同，不能互相冒充。
- 预览流未接入（阶段 1）：显示"预览未接入"，**MUST NOT** 用静态照片或"连接中"动画假装直播。
- 离线格不显示最后一帧：斜纹底 + 相机图标 + "没有画面信号" + 中断起始时间与持续时长。
- 画面加载失败：保留格子骨架与该格文字信息，显示"画面加载失败 · 重试"；不得留破图或整格空掉。
- 画面上的 ROI 框只在后端提供坐标时绘制；否则不画"示意框"。
- 图片 `alt` 描述画面内容与机位，不写"图片"。

### 2.4 全屏与墙屏

- 全屏（`F` 或筛选行按钮）隐藏顶栏与状态栏，只留筛选行（可 `H` 隐藏）与墙体；`Esc` 退出。
- 全屏时**MUST** 保留连接状态与时钟的最小显示，否则现场无法判断画面是否新鲜。
- 墙屏模式（1920）字号与行高 ×1.25，格子数由机位数决定；不得把桌面密度等比拉到墙屏。
- 进入全屏与退出都必须可键盘操作，且恢复焦点到触发按钮。

### 2.5 班次条

- 班次条上的数字与看板同名指标 **MUST** 一致（同一后端字段、同一统计口径）。对不上是缺陷，不是文案问题。
- 监控墙的计数按**机位数**（"待确认 1 机位"），看板与班次条按**记录数**（"待确认 2 件"）。两种口径不得混写。
- 等待时长取最久一件，不取平均；平均在看板上。

## 3. 看板

### 3.1 筛选与时间

- 时间范围（本班次/今天/近 7 天）、区域、统计口径 **MUST** 写入 URL。
- 筛选变化：保留面板框架，显示"更新中"，**MUST NOT** 整页闪骨架。
- 未结束的时间段（当前半小时/当前小时）不计入聚合，且必须在面板内写明（"12:00–12:30 还在统计，未计入"）。**MUST NOT** 默默画一个明显偏低的最后一点。
- 数据截止时间显示在筛选行；过期时按 §1.3 标记。

### 3.2 图表

- 每个图表 **MUST** 有 hover（十字准星或逐条 tooltip）与一个表格视图入口。表格视图回答"具体是哪一条"。
- **MUST** 单轴、单色相；**MUST NOT** 双轴、红绿多系列、环形合格率。
- 状态色 **MUST NOT** 用作数据系列色；状态只以"图标 + 文字"出现在表格与进度轨上。
- 图例规则：单系列不要图例（标题已说明），≥2 系列必须有图例，≤4 系列同时直接标注。
- 文字（数值、标签、图例）用 ink 层级，**MUST NOT** 使用系列色。
- 缺失数据（相机离线、无记录）**MUST** 画成缺失/斜纹断口，**MUST NOT** 画成 0。
- 点击图表元素（点/条/行）可下钻到记录页，并带上对应筛选；下钻是导航，不是重新计算。

### 3.3 指标块

- 指标块只显示后端给出的计数、时长、比率；**MUST NOT** 引入"合格率""通过率""效率分"。
- 需要人注意的指标（待确认积压）用琥珀顶边 + 说明文字，**MUST NOT** 整块染色或闪烁。
- 指标块点击可下钻到对应筛选的记录页；不可下钻的指标不做 hover 特效。
- 平均确认时长必须带单位与口径（"4 分 12 秒 · 从判定到人处理"）。

## 4. 工位详情与执行详情

### 4.1 详情布局

- 执行的四类事实组件只写一次：工位详情里是窄栏，`/executions/$id` 时是全页。**MUST NOT** 写两套。
- 头部必须显示：机位/工位、执行 ID、SOP 名称与版本、开始/结束时间、执行状态、数据快照时间。
- 四类事实块各自加载、各自报错；一个块失败不得隐藏其他块。
- 缺失事实显示 `—`（不适用）或 `不可用/未知`（应有但缺失）+ 原因；不得留空白。
- 关联告警必须区分 `PROCESS_COMPLIANCE` 与系统健康分类；**MUST NOT** 合成"相关告警 3 条"。

### 4.2 复核决定

- **MUST** 只渲染后端返回的允许动作；**MUST NOT** 硬编码"接受/驳回/判为漏步"的固定集合。
- 没有允许动作时显示只读状态与原因（"该执行已完成，无待复核步骤"），**MUST NOT** 显示灰色假按钮。
- 必填：决定、原因码、说明。说明不能只写"已阅"；最小长度由后端校验，前端同步提示。
- 提交前必须可见：原始模型输出、证据引用、模型/规则版本。
- 提交中：禁用重复提交并显示进行中；**MUST NOT** 乐观写入审计记录。
- 成功：刷新执行与审计，显示审计 ID；不覆盖用户刚输入的其他备注。
- 失败：保留输入，显示具体错误；网络错误可重试；冲突（409）时重新拉取并提示"状态已变化，请重新确认"，不得静默覆盖。
- 破坏性决定必须二次确认，文案写清后果；普通确认/标记已读不需要确认。
- 审计记录只追加；**MUST NOT** 提供编辑或删除。

### 4.3 证据

- 只有 `AVAILABLE` 的证据可以打开查看器；`PENDING_VERIFY`、缺失、校验失败 **MUST** 显示为不可用并给出原因。
- 证据查看器 **MUST** 从证据接口取图；**MUST NOT** 使用预览流、预览截图或占位图。
- 加载失败显示"证据加载失败"+ 重试；不留破图，不降级到预览。
- 证据不可用不得阻塞复核界面，但决定区必须提示"证据不可用"，并要求复核者确认已知晓（若后端允许在缺证据时决定）。
- 显示证据 ID、SHA-256、相机、时间、模型/规则版本；哈希可复制完整值。
- ROI 叠加只在后端提供坐标时显示。放大超过原始分辨率时提示。
- 证据胶片条支持键盘左右切换与 `Enter` 打开；不可用帧不可聚焦为可打开项，但可读。

### 4.4 预览（阶段 2）

- 预览 **MUST** 标注 `实时预览 · 不作为证据`；无时间戳或断流时不得显示为实时。
- 预览失败显示"预览不可用"，但设备/推理/平台健康仍然可见。
- **MUST NOT** 用最后一帧、静态图或"连接中"动画假装直播。
- 阶段 1 显示"预览未接入"，不要放假播放器。

## 5. 记录

- 记录页列出执行与告警，两者 **MUST** 分区或分 tab；计数分开，不显示混合总数。
- 默认排序：待确认/未处理优先，其次严重度，再按时间倒序。
- 筛选：类型、状态、原因码、机位、时间；筛选状态写入 URL。
- 行点击打开详情；证据不可用时明确显示不可用，不打开空查看器。
- 空态必须带筛选上下文，并给出清除筛选；有数据但被筛掉时不得显示"没有记录"。
- 数据过期时显示过期横幅；计数不得在过期时继续当实时数。
- 导出（若有）不得只导出当前页；必须说明导出范围与口径。

## 6. 标准（SOP）

- 阶段 1 只做：列表、版本历史、校验、发布、只读 DAG。**MUST NOT** 做图形化编辑器或拖拽节点。
- 校验结果来自后端；前端 **MUST NOT** 实现 SOP 语义校验。错误定位到步骤/字段，可滚动到对应行。
- 发布前必须校验通过；确认文案说明"发布后不可修改，执行将固定引用该版本"。
- 已发布版本只读；修改必须创建新版本。**MUST NOT** 允许直接编辑已发布版本。
- 执行详情中的 SOP 版本必须可追溯到发布版本；不得只显示名称。
- 列表/校验/发布各有 loading/error/empty；发布失败保留状态并显示原因。

## 7. 系统

- 阶段 1 默认只读：相机、绑定、模型、采样、Runtime 健康。没有 API 的配置不做假表单。
- 系统健康与工艺告警分开展示；预览失败不影响设备故障的显示。
- 配置修改（若阶段 1 提供）必须二次确认、等待服务端、记录审计；**MUST NOT** 乐观更新。
- 设备离线/断流/降级必须显示原因与最后心跳时间；不要只显示一个红点。
- "无事件"与"设备不可用"是两种状态，不能合并。
- 相机可用率在看板上的目标线必须可配置并显示来源；不得前端写死 95%。

## 8. 全局交互

### 8.1 导航与焦点

- 顶栏导航：监控墙、看板、记录、标准（系统在记录/设置入口下）。当前页有 `aria-current="page"` 与 2px ink 下划线。
- 提供跳过导航链接；路由切换后焦点到页面 `h1`。
- 抽屉/侧栏打开时焦点进入标题；`Esc` 关闭并把焦点还给触发器。
- 对话框是唯一使用焦点陷阱的场景；详情侧栏不是 modal，不锁页面滚动。
- 404 提供返回监控墙与搜索/导航；不要死链。

### 8.2 键盘

| 键 | 行为 | 范围 |
|---|---|---|
| `←` / `→` | 在格子间移动焦点 | 监控墙 |
| `↑` / `↓` | 上一行 / 下一行 | 监控墙 |
| `Enter` | 打开焦点所在机位 | 监控墙、记录 |
| `F` | 进入/退出全屏 | 监控墙 |
| `H` | 显示/隐藏筛选行（仅全屏） | 监控墙 |
| `1`–`4` | 切换时间范围 | 看板 |
| `Esc` | 关闭浮层/退出全屏/取消选择 | 全局 |
| `/` | 聚焦搜索 | 有搜索的页面 |
| `G` 然后 `M` / `A` | 跳到监控墙 / 看板 | 全局 |

- 单键快捷键在输入框、文本域、可编辑区域或下拉展开时不生效；`Esc` 例外。
- 不得拦截浏览器保留快捷键（`Cmd/Ctrl+L` 等）。
- 格子、表格行、图表元素都必须有可见焦点与可读标签（含机位、状态、时间）。

### 8.3 加载、空、错、过期

| 状态 | 规则 |
|---|---|
| 首次加载 | 与真实布局同形的骨架（格子/面板），不用居中 spinner |
| 后台刷新 | 保留内容，局部显示"更新中"；不整页闪骨架 |
| 空 | 说明为什么空 + 下一步；不画 0 值假图表 |
| 错误 | 直接说明发生了什么 + 重试；局部错误局部处理 |
| 过期 | 保留内容 + `快照已过期 Ns` + 刷新 |
| 部分失败 | 只降级失败面板/格子；导航、筛选、状态栏可用 |
| 无权限 | 隐藏动作或禁用并说明原因；服务端仍然强制 |

### 8.4 确认与反馈

- 需要确认：发布 SOP、破坏性复核决定、批量关闭、删除/中止、配置修改。
- 不需要确认：筛选、排序、全屏、选择、确认单条告警、打开证据。
- 成功反馈：用带审计 ID/对象 ID 的 toast；不要每次后台刷新都弹 toast。
- 失败反馈：就近显示；toast 只做补充，不承载唯一错误信息。
- 禁用按钮必须有原因（tooltip 或邻近说明），不能只变灰。
- 状态变化引起的格子重排 **MUST NOT** 弹出 toast；在状态栏说明即可。

### 8.5 权限

- 阶段 1 使用 dev 角色桩；前端按角色隐藏/禁用破坏性动作，但 **MUST NOT** 把前端隐藏当安全边界。
- 只读角色看不到发布/复核提交/配置修改；直接调用由服务端拒绝，并显示明确错误。
- 权限错误不吞掉：显示"当前角色无权执行此操作"，不假装成功。

### 8.6 时间与数字

- 显示本地时间；API 用 UTC；状态栏或 tooltip 标时区。
- 时间、ID、哈希、计数用窄体 + tabular numerals。
- 置信度显示 `0.71 / 0.92`（值/阈值）+ 模型版本；**MUST NOT** 显示为 `71%` 或"合格率"。
- 时长精确到秒；不用"约 15 分钟"替代 `15 分 28 秒`。
- 同一数量在墙/看板/班次条的写法一致；差异只能来自统计口径，且必须标注。
- 空白单元格用 `—`（不适用）或 `不可用/未知`（应有但缺失）；不留空让人猜。

## 9. 页面状态矩阵

| 页面 | 初始加载 | 空 | 错误 | 过期/断线 | 局部失败 |
|---|---|---|---|---|---|
| 监控墙 | 6 格同形骨架 | 筛选无结果，给清除筛选 | 单格错误，保留格内文字 | 画面降级为最后一帧 + 过期标记 | 单格/班次条单独报错 |
| 看板 | 4 指标块 + 4 面板骨架 | 该时段无记录，给换时段 | 单面板错误，其他照常 | 截止时间标过期 | 单图表失败不隐藏其他 |
| 工位详情 | 步骤 + 证据骨架 | 无活动执行，给最近执行入口 | 执行头/步骤区错误 | 预览不可用但健康可见 | 事件/健康分区报错 |
| 执行详情 | 证据 + 事实骨架 | 无证据显示"不可用/无证据" | 证据/事实/决定分别报错 | 提交冲突提示 | 单块事实失败不隐藏其他 |
| 记录 | 行骨架 | 当前筛选无记录，给清除筛选 | 列表错误，筛选保留 | 计数标过期 | 单条详情失败不影响列表 |
| 标准 | 列表/版本骨架 | 无 SOP，给导入说明 | 校验/发布错误就地显示 | 只读缓存标过期 | 版本历史失败不影响当前版本 |
| 系统 | 健康行骨架 | 无相机/绑定，给配置入口 | 健康查询错误 | 健康数据过期标记 | 单个设备行失败 |

## 10. 验收

交互规则至少由以下检查覆盖：

- WS 断线 → 顶栏变"连接中断" → 重连 → REST 刷新 → 恢复"已连接"；期间画面降级为"最后一帧"并带过期标记。
- 监控墙：筛选写入 URL；`←/→/↑/↓/Enter/F/H/Esc` 可用；全屏仍显示连接与时钟。
- 格子计数口径（机位）与看板/班次条（记录）分开显示，且同名数字对得上。
- 看板：每个图表有 hover 与表格视图；未结束时段不计入且有说明；离线画成缺失不画 0；点击可下钻并带筛选。
- `NEEDS_REVIEW` 详情只能渲染后端允许动作；缺少动作时只读，不出现假按钮。
- 证据 `PENDING_VERIFY` 不可打开，显示不可用；预览失败不隐藏设备健康。
- 记录页执行/告警分区计数分开；筛选写入 URL。
- 每个页面在 loading / empty / error / stale 下都不空白、不误导。
