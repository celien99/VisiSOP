# VISUAL QA — v1.0 / 检测系统控制台

**状态**：v1.0，随 `DESIGN_SYSTEM.md` v1.0 定稿。
**用途**：任何前端 UI 变更在合并前的视觉验收清单。不是"看起来不错"的主观评审，而是可逐项勾选、可截图的检查。
**效果图**：`assets/system-monitor.png`、`assets/system-analytics.png`。效果图只证明方向，不证明生产数据、交互或可访问性。

## 0. 怎么用

1. 在 PR 描述中贴出勾选结果，或链接到验收记录。
2. 关键页面至少提供 1600×1000 截图；布局改动再补 1440×900 与 1920×1080。
3. 使用固定夹具与固定时钟，不使用实时数据；否则截图不可复现。
4. 任何 L/T/C/D/S/A 项失败视为阻塞；例外必须写进 PR 并由设计/产品确认。
5. 视觉验收通过不等于功能验收通过；`bun run lint`、`bun run build`、`bunx playwright test` 仍需通过。
6. 新增的界面元素如果不在 `DESIGN_SYSTEM.md` §5 的组件清单里，先补文档再验收。

**必测视口**

| 视口 | 要求 | 说明 |
|---|---|---|
| 1440×900 | 必测 | 桌面最小目标 |
| 1600×1000 | 必测 | 设计稿基准 |
| 1920×1080 | 必测（墙屏） | 字号/行高 ×1.25，机位格数增加，不是等比拉伸 |
| 1024×768 | 必测（窄屏） | 监控墙降 2 列，看板面板纵向堆叠；不压到不可读 |
| 390×844 | 不阻塞 | 不是首要目标；不得出现不可关闭的遮挡或横向页面滚动 |

## 1. 10 秒理解测试（监控墙）

找一位没看过设计稿的同事，只给监控墙，不给解释，计时 10 秒，问：

1. 现在哪一格需要人处理？
2. 为什么？等了多久？
3. 哪一格没有画面？

**通过**：3/3 正确，且能指着具体格子说出依据。
**失败**：需要在 6 格里逐个读文字才能找到；把"离线"当成"异常"；把"待确认"读成"异常"。

**30 秒追问（看板）**：本班次作业量、异常次数、哪个机位可用率最低、复核积压最久多久。至少 3/4 正确。

**记录**：测试对象角色、日期、答错项；不要只写"通过"。

## 4. 颜色与语义（C）

- [ ] C1 绿 `--vs-ok` 只用于正常/完成/健康/在线；没有用来表示"正在运行"或给数字装饰。
- [ ] C2 琥珀 `--vs-warn` 只用于待确认/等待人/低于目标；小字用 `--vs-warn-ink`，不用原始色。
- [ ] C3 红 `--vs-crit` 只用于工艺异常/破坏性动作；系统/设备故障不用红。小字用 `--vs-crit-ink`。
- [ ] C4 灰 `--vs-off` 只用于离线/不可用/跳过；文字用 `--vs-off-ink`。
- [ ] C5 品牌、导航下划线、标题装饰不用信号色；只用 ink 或结构线。
- [ ] C6 所有状态都有图标或文字，不只靠颜色；灰度打印/色盲模拟（protan/deutan）仍可辨。
- [ ] C7 工艺异常与系统健康在视觉上分区；计数不混。
- [ ] C8 没有渐变、发光、玻璃拟态、彩色阴影、伪 3D；唯一纹理是离线斜纹。
- [ ] C9 图表只有一个色相 `--vs-series`；没有把状态色当数据系列。
- [ ] C10 没有半套浅色主题；`tokens.css` 的 LEGACY 变量没有被新组件引用。
- [ ] C11 对比度：正文 ≥4.5:1，小字元数据 ≥4.5:1，图形 ≥3:1；`--vs-crit` / `--vs-off` 没有被用作小字正文。

## 9. 视觉回归

阶段 1 先做人工截图验收；页面稳定后补 Playwright 截图对比。

**要求**：

- 固定夹具：机位、执行、相机、证据、告警、SOP 版本、看板时间段均为固定值。
- 固定时钟：例如 `2026-10-27 12:42:08`，避免相对时间漂移。
- 固定 WS：用夹具快照，不接真实推送；截图时动画设为 reduced motion。
- 截图目录：`frontend/tests/visual/__screenshots__/`；命名 `page-viewport.png`。
- 关键页面：监控墙、看板、工位详情、执行详情、记录、标准、系统。
- 视口：1600×1000（主）、1440×900、1920×1080；1024×768 至少一张。
- 更新基线必须经过设计评审，不能自动 `--update-snapshots`。
- 截图前等待字体加载；控制台除 favicon 404 外不得有错误。

**人工截图检查**：

- [ ] R1 截图是整屏视口，不是被裁切的元素截图；顶栏/状态栏完整。
- [ ] R2 没有滚动位置导致的错位；截图前回到顶部并等待布局稳定。
- [ ] R3 字体已加载（Archivo 窄体生效），没有 FOUT/回退字体混排。
- [ ] R4 没有占位图、破图、骨架残影。
- [ ] R5 没有控制台错误（favicon 例外需登记）。
- [ ] R6 至少一张"有离线 + 有待确认 + 有异常"的真实复杂状态，不只看全绿。
- [ ] R7 至少一张 16 机位、至少一张 1920 墙屏。

## 11. 只存在于效果图、不得直接进入生产的元素

- 所有机位名、工位名、执行 ID、时间、哈希、告警数、班次统计都是示意。
- 画面来自公开图库（Wikimedia Commons），作为"现场画面"的质感参考；生产必须是真实相机帧，且标注来源与时间。
- 实时预览是阶段 2；效果图中的画面不能作为阶段 1 的"实时"占位，阶段 1 显示"预览未接入"。
- 6 机位与 3×2 墙体是效果图假设；生产按 4/6/9/16 验证。
- 看板上的 1,284 / 17 / 23 / 4 分 12 秒均为示意，不是真实数据。
- 相机可用率 95% 目标线是示意；生产取自配置，并显示来源。
- 二元复核决定是简化；生产只渲染后端允许动作。
- 1600×1000 固定画布与 10px 小字是桌面稿密度示意；生产按 §2 的字号下限与响应式规则。
- ROI 框是示意；只有后端提供坐标时才画。
- 状态栏里的连接数、延迟、健康分只有在后端提供时显示。
